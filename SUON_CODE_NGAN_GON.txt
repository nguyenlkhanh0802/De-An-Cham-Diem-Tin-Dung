SƯỜN CODE NGẮN GỌN - FINTECH BOT
========================================

1. ĐIỂM BẮT ĐẦU
----------------------------------------

fintech_bot/__main__.py
  -> gọi cli.main()
  -> đọc cấu hình
  -> tạo ứng dụng
  -> chạy demo, local, live, Telegram hoặc backtest


2. CÁC FILE CODE CHÍNH
----------------------------------------

fintech_bot/app.py
- Nối nguồn dữ liệu, bộ phân tích, nơi lưu dữ liệu và giao diện.

fintech_bot/cli.py
- Nhận lệnh khởi động và điều khiển chương trình.

fintech_bot/config.py
- Đọc và kiểm tra file cấu hình TOML.

fintech_bot/domain.py
- Định nghĩa cổ phiếu, nến giá, dữ liệu tài chính và tín hiệu.

fintech_bot/market.py
- Quản lý ngày giao dịch và giờ đóng cửa từng sàn.


3. THƯ MỤC DATA
----------------------------------------

fintech_bot/data/

- vnstock_provider.py: lấy dữ liệu KBS qua Vnstock.
- vietcap.py: đọc và chuẩn hóa dữ liệu Vietcap.
- provider_manager.py: chọn KBS hoặc Vietcap.
- vnstock_sync.py: tải và cập nhật giá lịch sử.
- vietcap_sync.py: tải giá hiện tại và thông tin tài chính.
- daily_cache.py: lưu dữ liệu giá theo ngày trên máy.
- validation.py: kiểm tra dữ liệu hợp lệ.
- csv_provider.py: đọc dữ liệu từ CSV.
- replay.py: tạo dữ liệu giả để chạy thử.


4. THƯ MỤC STRATEGIES
----------------------------------------

fintech_bot/strategies/

- indicators.py: tính EMA và RSI.
- ema_rsi.py: tạo tín hiệu Mua, Bán hoặc Chưa có tín hiệu.


5. THƯ MỤC SERVICES
----------------------------------------

fintech_bot/services/

- scanner.py: quét từng mã và tạo tín hiệu.
- alerts.py: chọn người nhận và gửi cảnh báo.
- financial_filter.py: lọc cổ phiếu theo thông tin tài chính.
- live_data.py: cập nhật giá hiện tại.
- scheduler.py: chạy quét theo thời gian.
- backtest.py: chạy thử chiến lược trên dữ liệu cũ.


6. THƯ MỤC STORAGE
----------------------------------------

fintech_bot/storage/

- sqlite.py: lưu giá, tín hiệu, người theo dõi và thông báo.
- lock.py: tránh nhiều tiến trình cùng sửa dữ liệu.


7. THƯ MỤC BOT
----------------------------------------

fintech_bot/bot/

- commands.py: xử lý các lệnh người dùng.
- telegram.py: kết nối và gửi nhận tin Telegram.
- telegram_setup.py: nhập và lưu token Telegram.
- charting.py: tạo biểu đồ cổ phiếu.
- formatting.py: trình bày nội dung trả về.


8. LUỒNG CODE CHÍNH
----------------------------------------

Nguồn dữ liệu
  -> kiểm tra dữ liệu
  -> lưu dữ liệu theo ngày
  -> Scanner quét cổ phiếu
  -> tính EMA20, EMA50 và RSI14
  -> tạo tín hiệu Mua/Bán
  -> lưu vào SQLite
  -> gửi kết quả qua Telegram


9. FILE CHẠY
----------------------------------------

- start-local.cmd: chạy thử local.
- prepare-history.cmd: cập nhật giá lịch sử.
- prepare-vietcap.cmd: cập nhật thông tin tài chính.
- start-live.cmd: chạy với giá hiện tại.
- start-telegram.cmd: chạy bot Telegram.
- start-telegram-setup.cmd: cài token Telegram.


10. GHI NHỚ
----------------------------------------

- Chương trình chỉ phân tích dữ liệu theo ngày.
- KBS là nguồn chính, Vietcap là nguồn dự phòng.
- Giá hiện tại chỉ để hiển thị, không dùng tính tín hiệu.
- Bot không tự đặt lệnh chứng khoán.
